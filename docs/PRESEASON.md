# IGFL 프리시즌 확정 운영 규칙

2026-10-19 사용자 요청으로 확정했다. 프리시즌은 참가 팀과 선수를 늘리고 팀 구성·운영을 안정시키는 기간이다. 안내와 구현은 준비하되 실제 선수 가입·개인정보 저장소 승인·시즌 경기 등록·리그 메일 자동 발송은 계속 닫는다.

## 기간과 전환

2027년 봄학기 개강 전까지 운영한다. 마지막 경기일은 개강 전날로 안내하고, 정확한 날짜와 한국 시간 종료 시각은 KAIST 공식 학사일정 확인 후 별도 공지·설정한다. 현재 2027년 개강일의 공식 근거를 확인하지 못했으므로 날짜를 추측하지 않는다. 공개 문구는 **2027년 봄학기 개강 전까지 · 정확한 종료일 추후 공지**다. 기간 도래만으로 가입이나 정규리그를 자동 개통하지 않는다.

개통 전에 `LEAGUE_SEASON_ENDS_AT`를 확정하고 종료 전 끝나는 경기만 등록한다. 기존 일정이 있으면 일정 변경까지 포함해 종료일을 검토한다. 겨울 중간에 팀 수·인원·실제 경기 수를 점검하고 정규리그 개시 여부는 운영자가 별도 공지한다. 프리시즌 종료일이 정규리그 자동 시작일을 뜻하지 않는다.

## 경기 형식

| 항목 | 프리시즌 | 정규리그 |
| --- | --- | --- |
| 인원 | 5대5 또는 6대6 | 5대5 |
| 시간 | 전후반 각 15분 또는 20분 | 전후반 각 20분 |
| 휴식·시계·교체 | 휴식 5분·흐르는 시계·무제한 교체 | 동일 |
| 심판 | 없음·내부·외부 선택 가능 | 중립 심판 1명 필수 |
| 동점 | 승부차기로 승자 결정 | 동일 |
| 심판 없는 결과 | 양 팀 대표의 같은 버전 확인으로 자동 확정 | 허용하지 않음 |
| 심판 있는 결과 | 양 팀 확인 후 내부 심판, 외부 심판이면 운영진 최종 승인 | 동일 |

경기 전에 양 팀 대표가 인원·시간·심판 유무·일시·장소를 합의한다. 각 팀은 자기 팀 명단만 입력한다. 예정·실제 명단은 5대5에서 최소 5명, 6대6에서 최소 6명이며 교체 선수를 포함해 최대 20명이다. 양 팀의 일정·명단 확인 전에는 공식 일정이 확정되지 않는다. 심판 있는 경기는 기존 수락 절차도 충족해야 한다.

결과는 전체 스코어, 자기 팀 실제 출전 선수·득점을 각 팀이 제출한다. 정규시간·승부차기 스코어 및 자책골을 포함한 득점 합계가 일치하고 양 팀 대표(주장 또는 부주장)가 현재 버전을 확인해야 한다. 수정하면 이전 확인을 무효화한다. 불일치·이의·예외 검토가 있으면 심판 없는 경기라도 확정·Elo 반영을 보류한다. 운영진은 이견을 처리하며 정상 양 팀 확인을 생략하지 않는다.

심판비는 심판이 있는 경기당 20,000원, 팀별 10,000원 직접 지급이다. 심판 없는 경기는 심판비가 없다. 중립성·첫 수락 1명 배정·외부 심판 최종 승인 규칙은 유지한다. 취소·중단·몰수·정정은 [경기 규정](MATCH_RULES_DRAFT.md)을 따른다. 중단·몰수는 정상 경기 Elo에서 제외한다. 참가 자격·팀 6~20명·개인정보·팀 운영 규칙은 그대로다.

## 기록 분리

- 프리시즌 `preseason-2026-27`, 정규리그 `regular-2027`을 서로 다른 시즌 ID로 사용한다. 경기 생성 시 서버 설정으로 시즌 ID·구분·인원·시간·심판 방식을 고정한다. 클라이언트가 프리시즌이라고 보내 정규리그 검증을 우회할 수 없다.
- Elo는 각 시즌 초기 1000·K32·척도400, 점수 차 제외다. 프리시즌 점수를 정규리그로 이월하지 않는다. 이후 정규시즌 간 이월과 컵 세칙은 미정이다.
- 선수별 최근 출전 5경기 득점, 내부 심판 공로도 해당 시즌만 집계한다. 심판 없는 경기는 심판 공로에 포함하지 않는다.
- 랭킹보드에서 시즌 버튼으로 기록을 전환한다. 과거 경기 지연 확정·정정도 원래 시즌에만 반영하고 모든 시즌의 Elo 원장을 유지한다. 시즌이 다른 경기로 재경기를 연결하지 않는다.

## 설정·검증·인계

`src/competition.mjs`가 시즌 식별자·기간 문구·시간 계산의 공통 원본이다. 공개 운영 안내는 `#operations`이며 로그인·서버 연결 없이도 읽을 수 있다. 등록 화면은 서버 `competitionPhase`에 따라 프리시즌 선택지를 제공한다.

Apps Script의 `configurePreseasonSettings()`는 모든 개통 스위치가 닫힌 상태에서만 시즌 구분·ID·이름을 준비한다. 기존 다른 시즌 경기가 있으면 실행을 거부한다. 데이터 삭제·초기화·역할 변경·메일 발송·가입 개통을 하지 않는다. 정규리그 전환 시 다른 시즌 ID, `LEAGUE_PHASE=regular`, 새 이름·종료일을 함께 설정한다. 기존 프리시즌 종료일도 시즌별 보관 메타데이터에 보존하고 개인정보 보관 만료를 확인한다.

자동 검증은 `tests/preseason.test.mjs`의 7개 시나리오로 무심판 확정·명단 인원·시간·버전·스코어 불일치·이의·내외부 심판·일정 변경·시즌 분리·중복 확정·지연 정정·두 시즌 원장·운영 설정 안전성을 다룬다. 브라우저는 합성 데이터에서 주장·부주장의 6대6·15/5/15·심판 없음 일정·명단·결과·양 팀 확인과 프리시즌 Elo 갱신, 정규리그 초기 1000 유지 및 모바일 안내 화면을 확인했다. 합성 시간 이동은 종료 후 결과 흐름 검증에만 사용했다. 실제 선수·경기·메일은 만들지 않았다.
