# IGFL 경기 및 예외 처리 규정 초안

2026-10-16 검토안. 기존 확정 사항을 유지하고, 미정인 예외 처리를 제안한다. 시즌 날짜와 컵·진출 규칙은 아직 정하지 않는다. 이 문서 작성만으로 취소·몰수·확정 후 정정 기능을 개통하거나 과거 기록을 변경하지 않는다.

## 적용 기준

[FIFA Futsal Laws of the Game 2025–26](https://cdn.sanity.io/files/oyf3dba6/production/ef303b9de23b797d2c74e1902b9f8ee2d07a6da4.pdf)을 경기 판단의 기준으로 삼는다. [미국축구협회 공식 규정 목록](https://www.ussoccer.com/refereeing/documents)에서 연결한 원문이다. 아래 IGFL 운영 제안은 FIFA가 정한 제출 기한·몰수 스코어가 아니다.

| 공인 풋살 기준 요약 | 관련 조항 |
| --- | --- |
| 골키퍼 포함 5명, 무제한 교체. 3명 미만이면 시작·재개 불가 | Law 3 |
| 공식 대회 교체 선수 최대 9명. 다른 경기의 추가 인원은 사전 합의·심판 고지 필요 | Law 3 |
| 심판 2명, 전후반 각 20분의 실제 경기 시간, 하프타임 최대 15분 | Laws 5–7 |
| 팀당 전후반 각각 1분 타임아웃 1회, 미사용분 이월 없음 | Law 7 |
| 승자 필요 시 승부차기 가능. 각 팀 5회 후 동률이면 서든데스 | Law 10 |
| 오프사이드 없음. 킥인·재개와 골키퍼의 해당 상황에 4초 제한 적용 | Laws 11, 12, 15–17 |
| 전후반별 팀 누적 직접 프리킥 반칙 6회부터 벽 없는 직접 프리킥, 위치별 예외 적용 | Law 13 |
| 퇴장자는 복귀 불가. 수적 열세 2분과 득점에 따른 보충 조건 적용 | Law 3 |
| 중단 경기는 재경기가 원칙이며 대회 규정·주최자가 달리 정할 수 있음 | Law 7 |

경고·퇴장·접촉·골키퍼·재개 세부 판단은 원문에 따른다. 모든 슬라이딩을 일률적으로 반칙으로 처리하는 문구를 ‘공인 규칙’으로 추가하지 않는다. 안전하지 않은 시설·장비에서는 심판이 진행을 중단할 수 있다.

## 기존 확정 사항과 조정 필요 사항

5대5, 전반 20분·휴식 5분·후반 20분, 무제한 교체, 동점 시 승부차기, 중립 심판 배정, 심판비 20,000원(팀별 직접 10,000원)은 유지한다. 현재 시스템은 한 명의 최종 담당 심판을 배정한다.

공인 기준을 그대로 적용하려면 심판 2명과 정지 시간 계측 운영을 준비해야 한다. 구장 예약·비용·자원봉사 인원을 고려한 IGFL 권장 조정안은 **주심 1명과 중립 기록·시간 담당 1명, 흐르는 시계**다. 부상·퇴장 처리·PK·타임아웃 등 심판이 명시한 중단 때만 시간을 멈춘다. 이는 공인 기준을 그대로 충족한다는 뜻이 아니며 사용자 결정 전 미적용이다. 흐르는 시계를 택해도 퇴장으로 인한 수적 열세는 별도 유효 경기 시간으로 계측한다. 정확한 계측이 어렵다면 공인 정지 시계 운영을 채택한다.

팀 등록 정원 6~20명과 경기 출전 명단은 구분한다. IGFL 경기 명단은 최대 20명으로 두되 양 팀·심판에게 경기 전 고지·합의하는 방안을 제안한다. 킥오프 전 명단을 확정하고 경기 결과에서는 그 명단 중 실제 출전자를 고른다. 이 명단 잠금은 아직 서버에 없다. 승부차기 득점은 정규 스코어와 개인 득점에 합산하지 않는다.

## IGFL 예외 운영 제안

| 상황 | 권장 처리 |
| --- | --- |
| 상대 팀 일정 동의 | 양 팀 대표가 같은 경기의 시간·장소·상대·자기 명단을 확인한 뒤 심판 배정이 완료되면 공식 일정으로 전환 |
| 심판 미배정·미응답 | 공식 경기로 전환하지 않음. 시작 24시간 전까지 미배정이면 대표에게 재요청 안내. 늦게 잡은 경기도 배정 전에는 비공식 상태 |
| 양 팀 합의로 시간·장소 변경 | 새 일정 버전에서 양 팀 재확인·심판 재수락. 기존 수락을 자동 승계하지 않음 |
| 심판 취소·당일 부재 | 적격 대체 심판을 양 팀과 확인하고 기록. 대체 불가 시 연기 또는 비공식 경기로 처리하고 Elo 제외 |
| 기상·구장 폐쇄·안전 문제 | 심판이 중단·연기 판단. 경기 미완료 시 정상 결과 확정을 막고 운영진 검토. 개인 부상 진단·의무 기록은 받지 않음 |
| 지각·시작 인원 부족 | IGFL 시작 기준은 각 팀 5명으로 제안. 예정 시각부터 10분 대기 후 불충족이면 심판 보고·운영진 확인. 대기 10분은 공인 규정이 아닌 IGFL 제안 |
| 경기 중 3명 미만 | 즉시 중단. 현재 스코어를 정상 종료 스코어로 자동 인정하지 않고 운영진 검토 |
| 재개 불가능한 중단 | 원칙적으로 전체 재경기. 원래 경기의 임시 득점·출전 기록·Elo는 집계하지 않고 새 경기로 연결. 징계 검토 기록은 별도 유지 |
| 일방 불참·부정 출전·진행 거부 | 양 팀·심판 자료를 받고 운영진이 책임 판단. 몰수 0:3 표기는 IGFL 행정 기록으로 제안. 미완료·무경기 몰수는 Elo·득점·심판 공로 집계에서 제외하고 실제 미지급 심판비는 당사자 간 합의 |
| 결과 미제출·미확인 | 종료 후 48시간 내 각 팀 제출·확인 권장. 양 팀 확인 뒤 심판은 24시간 내 최종 승인 권장. 초과 시 운영진 알림만 보내고 무응답을 승인으로 취급하지 않음 |
| 스코어·승부차기 불일치 | 경기 확정과 Elo 차단, 운영진 검토함·메일 알림. 대표가 자기 제출분 수정 → 새 버전에 양 팀 재확인 → 최종 승인 |
| 확정 후 오기·자격 이의 | 확정 후 7일 이내 요청 권장. 운영진이 증거·사유를 기록하고 정정 버전을 만듦. 경기 중 사실 판단을 단순 불만으로 소급 번복하지 않음. 중대한 부정은 별도 검토 |
| 퇴장 이후 출전 정지 | 다음 공식 경기 1회 출전 정지를 IGFL 기본 징계로 제안. 폭력·위협·반복 위반의 추가 징계는 운영진 심의. 이 출전 정지는 FIFA 경기 중 수적 열세 규칙과 별개 |

불참·몰수 여부와 취소 시 심판비 보상은 자동 결제·운영진 정산으로 연결하지 않는다. 현재의 팀별 직접 지급 원칙을 유지한다. 출전 자격을 잃거나 탈퇴한 선수가 나중에 생겼다는 사실만으로 이미 정상 확정한 과거 경기를 무조건 무효화하지 않는다. 부정 출전 여부는 경기 당시 자격으로 검토한다.

## 자책골과 확정 결과 정정

자책골은 상대 팀 스코어에 반영하고 개인 득점 순위에는 합산하지 않는다. 각 대표는 자기 팀 실제 출전자·일반 득점·자책골만 기록한다. 예를 들어 A팀의 최종 3득점이 일반 득점 2점과 B팀의 자책골 1점이면 A의 일반 득점은 2점, B는 자기 자책골 1점을 기록한다. 양 팀 제출을 합쳐 전체 스코어와 대조하며 상대 선수 기록 수정 권한은 주지 않는다.

확정 후 정정은 원본 삭제 대신 정정 사유와 새 결과 버전을 남긴다. 양 팀 대표 재확인 후 내부 배정 심판이 최종 승인하고, 외부 심판 경기에서는 운영진이 최종 승인한다. 정규 스코어·승자·유효 경기 여부가 바뀌면 해당 경기와 이후 경기를 시간순으로 다시 계산하고 중복 Elo 반영을 막는다. 이력도 개인정보 보관·탈퇴 정책을 따라야 한다.

## 구현과 추가 결정

현재는 정상 경기 사전 등록·첫 심판 수락·양 팀 제출·버전별 확인·내부/외부 최종 승인·불일치 차단을 구현했다. 취소/연기·명단 잠금·자책골·중단/몰수 유형·징계·기한 알림·확정 후 정정은 이 초안의 채택 후 구현해야 한다. 없는 기능을 운영 화면에서 이미 지원한다고 안내하지 않는다.

우선 정할 사항은 시계 방식과 심판 구성이다. 나머지 표의 기한·몰수 표기·징계는 IGFL 기본안으로 함께 검토할 수 있다. 시즌 마감·토너먼트·컵 Elo·다음 시즌 이월은 별도 결정으로 남긴다.
