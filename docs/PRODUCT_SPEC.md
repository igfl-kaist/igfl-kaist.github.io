2026-10-19 최신 결정: [프리시즌 규칙](PRESEASON.md)을 확정했다. 프리시즌에 한해 5·6대6, 전후반 15·20분, 심판 없는 경기를 허용하며 무심판 결과는 양 팀 대표의 같은 버전 확인으로 자동 확정한다. 기록은 정규리그와 분리하고 정규리그 Elo는 1000에서 새로 시작한다. 기간은 2027년 봄학기 개강 전까지이며 정확한 종료일은 추후 공지한다. 아래 심판 1명·5대5·20분 기본 규칙은 정규리그 기준이다. 실제 가입·시즌·리그 자동 메일은 계속 닫는다.

기준일: 2026년 10월 16일. 이 문서는 현재까지 사용자가 확정한 요구 사항과 이를 구현하기 위한 제약을 정의한다. 아직 확정하지 않은 운영 세칙과 기술 선택은 [결정할 사항](DECISIONS.md)에 모아 두었다.

## 서비스 목적과 범위

ISE·GSDS 구성원과 해당 학과 교수의 지도를 받는 타 학과 대학원생이 참가하는 풋살 리그다. 정기 대진표 없이 팀이 자율적으로 일정을 잡고, 심판이 있는 경기를 치른 뒤 확인된 결과를 홈페이지에 누적한다. 확정된 경기 결과로 팀 Elo 파워랭킹을 갱신한다.

리그명은 IGFL이며 영문 정식명은 ISE & GSDS Futsal League다. 홈페이지의 기본 화면은 리그 소개 홈이다. 팀 파워랭킹은 하위 랭킹보드에서 제공한다. 선수 등록, 팀 등록과 팀 정보, 경기 사전 등록, 결과 입력과 확인, 심판 배정, 운영진 관리 기능을 제공한다. 학교 도메인에 의존하지 않는 독립 운영을 지향하며, KAIST SSO는 사용하지 않는다.

홈페이지 구축은 아직 시작하지 않는다. 이 문서를 작성하는 작업 자체는 외부 저장소 생성이나 서비스 배포를 허가하는 요청이 아니다.

구현 시 전체 인계는 [최종 구현 지침](IMPLEMENTATION_BRIEF.md)을 먼저 읽는다. 같은 디자인을 재현할 수 있도록 [승인 시안 원본](design/igfl-approved-mockup.html)도 저장소에 보관한다. 미정인 예시값은 [결정할 사항](DECISIONS.md)에서 구분한다.

## 선수 자격과 등록

다음 세 조건 중 하나 이상을 충족해야 한다.

1. GSDS 또는 ISE 소속 대학원생.
2. GSDS 또는 ISE 소속 교직원.
3. GSDS 또는 ISE 소속 교수를 지도교수로 둔 다른 학과 대학원생.

예를 들어 기계공학과 대학원생도 지도교수가 ISE 소속이면 참가할 수 있다. 세 번째 조건을 모든 외부인에게 확대하지 않는다.

KAIST 공식 이메일을 인증하고 필수 선수 정보를 입력하면 바로 등록한다. 운영진의 사전 가입 승인은 없다. 참가 자격은 이용자가 신고하고, 운영진은 의심 사례나 확인 요청이 있을 때 별도로 검토한다. 학교 이메일 소유 확인을 학과·재학 상태의 자동 검증으로 표시하지 않는다.

인증은 숫자 6자리 난수를 이메일로 보내고 홈페이지에 입력받는 방식이며 유효시간은 발급 후 5분이다. 5분은 인증번호의 유효시간으로 해석하며 인증 완료 이후 프로필 입력 시간을 5분으로 제한하지 않는다. 재발급 시 이전 번호를 무효화하고 이메일 변경 시 다시 인증한다. 실제 구현에서는 서버에서 난수를 발급·검증하며 일회 사용, 유효시간, 이메일·인증 시도 연결을 강제한다. 재발송 간격·시도 횟수·발송 제한은 구현 전 정한다.

정보 입력 단계에 짧은 개인정보 수집 및 이용 동의(필수)를 추가하고 미동의 시 등록을 완료하지 않는다. 수집 목적·항목·공개 범위를 안내하며 최종 보관 기간과 탈퇴 후 처리 기준 등 문안은 운영정책 확정 후 완성한다. 시안 문구를 확정된 개인정보 처리정책으로 간주하지 않는다. 심판 가능 여부 입력 옆에는 경기당 20,000원 수당과 각 팀 10,000원 직접 지급을 안내한다.

## 팀 등록과 선수 이동

- 팀 등록 자격은 등록 선수 6명 이상 20명 이하다.
- 주장과 부주장 정보를 받는다.
- 팀 등록 신청을 운영진이 승인하면 정식 팀이 된다.
- 한 선수는 동시에 둘 이상의 팀에 소속될 수 없다.
- 무소속 선수를 허용한다.
- 별도 이적 승인 기능을 두지 않는다. 본인 탈퇴로 무소속이 된 뒤 새 팀에 영입된다.
- 주장과 부주장 모두 경기 일정 등록, 선수 영입·방출 등록, 팀 대표로서 경기 결과 확인 권한을 가진다.
- 팀 인원이 6명 미만이면 리그 참가 유예로 전환하고 공식 경기·현재 순위 참여를 보류한다. 사용자 범위인 1~2개월 중 60일을 기본안으로 두며 기한 내 충원 시 복귀, 미충원 시 팀을 리그 제외 처리한다. 과거 기록·계정을 삭제하지 않는다. 20명을 초과하는 가입은 허용하지 않는다.

영입 동의는 팀에서 협의하고 주장·부주장이 등록한다. 시스템의 별도 선수 동의 단계를 강제하지 않는다. 선수는 내 선수 활동에서 팀 탈퇴를 누르면 팀명·취소/탈퇴하기 팝업을 확인한 뒤 대표 승인 없이 즉시 무소속이 된다. 계정·과거 기록은 보존한다. 주장·부주장도 본인 탈퇴 시 권한을 즉시 잃는다.

처음 팀 등록 시 대표를 지정하고 이후 기존 대표가 팀 관리에서 새 주장·부주장 교체를 요청한다. 후보는 서로 다른 현재 소속 선수다. 운영진 승인 전에는 기존 대표가 유지되고 승인 시점부터 원자적으로 교체한다. 승인 직전 소속과 요청 버전을 재검사한다. 대표 공석은 잔존 대표 또는 운영진이 승인 절차로 복구한다. 두 대표의 동일 권한은 개인정보 열람 권한을 의미하지 않는다.

### 팀 공개 정보

팀 상세 화면에서 팀 정보, 현재 소속 선수의 이름과 연구실, 주장·부주장, 파워랭킹과 경기 기록을 제공한다. 팀명은 등록에 필요하며, 팀 소개·엠블럼 등 추가 입력 항목의 필수 여부는 구현 설계에서 정한다. 선수의 학번/사번·이메일·지도교수는 공개 팀 응답에 포함하지 않는다.

### 선수 모집과 가입 요청

모집 중인 팀 카드와 팀 상세에 주황색 선수 모집 중 배지를 표시한다. 주장과 부주장이 팀의 모집 상태를 관리하는 구성을 따른다. 무소속 등록 선수는 해당 팀 상세에서 주장·부주장에게 문의하거나 가입을 요청할 수 있어야 한다. 연락 경로는 홈페이지 내 문의·가입 요청으로 설계하고 팀 대표의 개인 이메일이나 연락처를 공개하지 않는다.

가입 요청은 두 대표가 홈페이지에서 확인하고 별도 이메일은 보내지 않는다. 문의만으로 팀 소속을 만들지 않으며 실제 영입 시 20명 정원과 대상의 무소속 여부를 검증한다. 기존 팀에 있는 선수는 먼저 본인이 탈퇴해야 한다. 요청 취소·중복·반려의 상세 UX는 구현에서 정하되 별도 이적 승인을 재도입하지 않는다.

## 경기 규칙과 사전 등록

| 항목 | 확정 규칙 |
| --- | --- |
| 대진 | 팀끼리 자율적으로 협의 |
| 인원 | 경기 중 5대5 |
| 시간 | 전반 20분, 휴식 5분, 후반 20분 |
| 교체 | 무제한 |
| 동점 | 승부차기로 승자 결정, 공식 최종 결과에 무승부 없음 |
| 공식 경기 | 심판이 있는 경기만 인정 |
| 심판 중립성 | 경기하는 두 팀 중 어느 팀에도 소속되지 않은 사람 |

경기 전에 다음 정보를 홈페이지에 등록한다.

- 경기하는 양 팀.
- 경기 날짜와 시작 시각.
- 장소.
- 심판 이름과 내부·외부 구분.
- 본인 팀 사전 출전 명단. 상대 팀은 해당 팀 대표가 별도로 등록한다.

날짜와 시간은 이용자 화면에서 한국 시간으로 표시한다. 내부 심판은 등록 선수 중 심판 가능으로 표시하고 양 팀 소속이 아닌 후보를 한 명 이상 복수 선택한다. 선택한 모든 후보에게 동시에 홈페이지 요청과 이메일 알림을 보낸다. 홈페이지에서 가장 먼저 유효하게 수락한 한 명을 담당 심판으로 확정하고 나머지 요청은 종료한다. 배정되지 않은 일정과 명단은 대기 상태로 보관하고 공식 일정 등록은 보류한다. 배정 확정 후 공식 등록 상태로 전환한다. 외부 심판도 허용하며, 외부 심판에게 선수 자격을 충족하는 선수 가입을 강제하지 않는다. 외부 심판의 수락 확인 방식은 아직 확정하지 않았으며 시안에서는 대표가 확인을 기록한다.

동시 수락은 서버의 트랜잭션·조건부 갱신으로 처리하여 한 경기의 담당 심판이 두 명이 되지 않게 한다. 늦은 수락·종료된 요청·취소되거나 수정된 일정 버전의 요청은 거절한다. 수락 시 중립성을 다시 검사한다. 이메일 수신 시각이나 클라이언트의 버튼 클릭 시각으로 승자를 정하지 않고 서버가 처음 유효하게 확정한 수락을 기준으로 한다. 요청 알림 실패가 요청 기록을 없애서는 안 되며 재시도는 중복을 방지한다.

사전 출전 명단은 로그인한 대표의 본인 팀 소속 선수만 체크박스로 보여 주고 복수 선택한다. 상대 팀 명단을 대신 입력하거나 수정할 수 없다. 양 팀이 같은 경기 ID 아래에 자기 명단을 각각 등록한다. 전체 경기 출전 명단은 교체 선수를 포함하므로 5명으로 제한하지 않는다. 일정 변경·취소, 사전 명단 수정 마감, 실제 출전 명단 확정 시점은 미정이다.

## 경기 결과 입력과 출전 기록

경기 결과는 홈페이지에서 입력한다. 각 팀의 주장 또는 부주장이 전체 스코어와 자기 팀 실제 출전 명단·득점 기록을 각각 제출한다. 상대 팀 선수의 출전·득점 내역을 대신 작성하지 않는다. 이메일로 결과를 제출하거나 이메일 회신을 결과 입력으로 사용하지 않는다.

| 정보 | 규칙 |
| --- | --- |
| 정규시간 스코어 | 양 팀의 득점 수를 별도로 기록 |
| 승부차기 스코어 | 정규시간 동점인 경우 별도 기록 |
| 최종 승리 팀 | 정규시간 또는 승부차기로 결정 |
| 실제 출전 선수 | 본인 팀 명단 체크박스로 복수 선택, 사전 명단과의 변경 이력 보존 |
| 득점 선수 | 본인 팀 실제 출전 선수 중 선택 |
| 선수별 득점 수 | 본인 팀 정규시간 득점과 일치하도록 검증하되 자책골 처리 세칙은 별도 결정 |
| 담당 심판 | 사전 배정 내역과 연결 |

승부차기 득점을 정규시간 팀 득점이나 선수의 정규시간 득점에 합산하지 않는다. 결과 화면에서 정규시간 스코어와 승부차기 스코어를 구분한다. 연장전은 확정된 규칙에 없으므로 임의로 추가하지 않는다.

## 결과 확인과 최종 승인

팀별 확인은 해당 팀의 주장 또는 부주장 중 한 명이 수행하면 된다. 같은 팀의 두 사람 모두 확인하도록 요구하지 않는다. 자기 팀 기록 제출 시 확인을 함께 받는 UX를 사용한다. 최종 승인 전에 양 팀의 개별 제출·확인이 각각 필요하다.

서버에서 양 팀이 제출한 전체 스코어를 같은 팀 순서로 정규화해 대조한다. 정규시간 스코어와 동점 경기의 승부차기 스코어가 모두 일치해야 다음 승인 단계로 넘어간다. 단순히 승리 팀이 같다는 이유로 일치로 처리하지 않는다. 불일치하면 자동 확정 및 Elo 반영을 중단하고 운영진 이메일 알림·홈페이지 검토 항목을 생성한다. 양 팀의 원본 제출값과 버전을 보존하며 한쪽 값으로 덮어쓰지 않는다. 정정·재제출 후에도 양 팀 확인과 최종 승인 절차가 필요하다.

| 심판 유형 | 절차 |
| --- | --- |
| 내부 심판 | 양 팀 각각 자기 기록 제출·확인 → 스코어 일치 → 배정된 내부 심판 최종 승인 → 자동 확정 |
| 외부 심판 | 양 팀 각각 자기 기록 제출·확인 → 스코어 일치 → 운영진이 외부 심판 확인 후 최종 승인 → 자동 확정 |

내부 심판의 수락·결과 확인·최종 승인은 홈페이지에서 처리한다. 외부 심판 확인을 운영진이 기록하는 화면을 두되, 외부 심판용 계정이나 별도 이메일 승인 기능을 임의로 추가하지 않는다.

결과가 확정되면 공식 경기 기록과 팀 파워랭킹을 자동 갱신한다. 이견 또는 스코어 불일치가 있을 때 운영진이 개입하며, 외부 심판 경기의 최종 승인은 평상시에도 운영진이 담당한다.

### 승인 상태와 데이터 정합성

구현 상태명은 설계에 맞게 정할 수 있으나 아래 구분은 보존한다.

- 대기 일정·명단 저장과 내부 심판 수락 대기. 담당 심판 배정 전에는 공식 등록이 아니다.
- 예정 경기.
- 결과 작성 중.
- 양 팀 확인 대기.
- 양 팀 스코어 불일치·운영진 검토 대기.
- 내부 심판 또는 운영진 최종 승인 대기.
- 이의 검토 중.
- 결과 확정.

확인·승인은 특정 결과 버전에 귀속한다. 스코어·출전 명단·득점 내역을 수정하면 기존 확인을 무효화하고 양 팀부터 재확인한다. 이전 화면에서 보낸 승인 요청으로 변경된 기록을 확정하지 못하게 한다. 확정 전에 이의가 제기되면 분쟁 해결 전까지 자동 확정을 막는다.

누가 언제 어떤 버전을 확인·승인·수정했는지 기록한다. 결과 확정과 Elo 적용은 중복 클릭·동시 요청에도 한 번만 처리한다. 이미 확정된 결과의 이의 처리 및 정정 권한·기한은 세칙 확정 후 구현한다. 운영진의 정정 사유와 이력은 남겨야 한다.

## Elo 파워랭킹

- 상대 팀의 전력을 고려하는 Elo 방식을 사용한다.
- 점수 차는 계산에 반영하지 않는다.
- 정규시간 동점 경기도 승부차기로 최종 승자를 결정한다.
- 공식 확정 경기만 반영한다. 작성 중·확인 대기·이의 검토 중 결과는 반영하지 않는다.
- 초기 1000·K=32·기대 승률 척도 400, 승리 1·패배 0으로 계산한다. 승부차기도 동일하다. 경기 일시·경기 ID 순서로 계산·재계산하며 점수 저장 정밀도를 유지하고 정수로 표시한다. 동점은 공동순위이고 시즌 이월만 미정이다. [계산 규칙](RATING_POLICY.md)을 따른다.
- 하위 랭킹보드에서 전체 팀의 현재 점수와 순위를 확인할 수 있어야 한다. 확정 결과가 생기면 다른 이용자의 열려 있는 랭킹 화면에도 갱신이 전달되어야 한다.
- 랭킹보드는 현 시즌 각 선수의 최근 실제 출전 5경기 정규시간 득점 상위 3위와 현 시즌 공식 내부 심판 경기 수 상위 3위를 표시한다. 5경기 미만은 실제 출전 수, 동률은 공동순위와 경계 동률 전원 포함, 0기록은 제외한다. 외부 심판은 기본 공로 보드에서 제외한다. 전체 개인 순위·개인 Elo는 추가하지 않는다.

구현 시 경기별 계산 전 점수, 계산 후 점수, 변화량, 규칙 버전, 계산 순서를 보존한다. 확정 경기 정정이나 과거 경기의 늦은 확정에 대응할 수 있도록 같은 기록과 같은 순서로 점수를 재계산할 수 있어야 한다. Elo 계산과 최종 저장을 브라우저가 임의로 수행하지 못하게 한다.

## 시즌과 컵 대회

사용자는 10월 말 또는 11월에 상위 8개 팀 토너먼트와 컵 대회를 진행하고, 이후 약 3개월의 휴지기를 갖는 구상을 제시했다. 정확한 날짜와 다음 시즌 시작일은 고정하지 않는다.

상위 8개 팀 토너먼트와 컵 대회가 같은 대회인지 별도 대회인지, 순위 마감 시점, 참가 최소 경기 수, 동률 진출 기준, 대진·시드 방식, 컵 경기 Elo 반영, 휴지기 경기 인정과 시즌 점수 이월은 미정이다. 이를 임의로 확정하거나 토너먼트를 자동 실행하지 않는다. 시즌별 경기·순위·선수 소속 이력을 보존할 수 있는 구조를 준비한다.

## 심판 풀과 비용

심판 가능으로 등록한 선수들을 홈페이지에서 심판 후보로 관리한다. 경기 양 팀 소속 선수는 제외하고 복수 후보에게 동시 요청한 뒤 첫 유효 수락자 한 명을 배정한다. 일정과 요청 중·배정 확정·요청 종료 상태는 홈페이지에서 확인한다. 같은 시간 중복 배정의 처리와 심판 요청 만료·전원 거절 후 재요청 세칙은 미정이다.

심판비는 경기당 총 20,000원이며 각 팀이 10,000원씩 심판에게 직접 지급한다. 운영진은 수납·정산에 개입하지 않는다. 홈페이지 내 결제, 송금, 계좌 수집, 운영진 정산 기능은 범위에 포함하지 않는다. 납부 여부 추적도 아직 요청된 기능이 아니다.

## 이메일과 홈페이지 알림

이메일 용도는 다음 세 범주로 제한한다. 심판 배정 요청 알림은 최신 사용자 요구로 추가되었다.

1. 선수 가입과 로그인 시 KAIST 이메일 6자리 인증.
2. 운영진에게 필요한 업무 알림.
3. 선택된 내부 심판 후보 각자에게 보내는 경기 배정 요청 알림.

운영진 이메일 대상은 팀 등록 신청, 선수 자격 확인 요청, 경기 결과 이의 제기, 양 팀 제출 스코어 불일치, 외부 심판 경기 최종 승인 대기다. 자격 확인은 자동 가입 이후의 예외 검토다. 대표 교체는 우선 홈페이지 요청함으로 관리하며 별도 이적 확인·메일은 만들지 않는다.

주장·부주장·내부 심판의 요청과 승인 대기는 홈페이지 안에 표시한다. 내부 심판 후보에게 배정 요청 이메일을 보내되 결과 승인 요청·확정 결과나 팀 대표의 일반 일정 알림 메일은 추가하지 않는다. 심판 요청 이메일은 로그인 후 홈페이지 요청으로 연결하며 메일 열람·링크 접속만으로 수락하지 않는다. 운영진 이메일 역시 관리 화면으로 연결하는 알림이다. 이메일 발송 실패가 원래 신청이나 승인 대기 기록을 삭제해서는 안 된다.

세션이 없거나 만료된 로그인은 이메일 OTP를 요청한다. 세션이 유효한 화면 이동에는 재발송하지 않는다. 비밀번호·복구 메일은 제거하며 이메일 변경과 뉴스레터는 별도 범위다.

## 역할과 접근 권한

| 역할 | 허용할 주요 동작 |
| --- | --- |
| 비회원 | 공개 파워랭킹·팀 정보·공개 경기 기록 열람 |
| 등록 선수 | 본인 정보 관리, 팀 관련 신청, 심판 가능 여부 설정 |
| 주장·부주장 | 자기 팀 관리, 영입·방출 등록, 경기 일정·출전 명단·결과 등록, 자기 팀 결과 확인 |
| 배정된 내부 심판 | 배정 수락, 담당 경기 기록 열람과 최종 승인, 이의 제기 |
| 운영진 | 팀 등록·대표 교체 승인, 선수 자격 예외·유예 상태 관리, 분쟁 처리, 외부 심판 경기 최종 승인 |

팀 대표나 심판이어도 다른 선수의 비공개 개인정보는 열람할 수 없다. 공개 이름·연구실과 경기 처리에 필요한 명단·기록만 제공한다. 운영진 권한 부여는 신뢰할 수 있는 관리자 경로에서만 수행하고 일반 회원이 자신의 역할을 변경하지 못하게 한다.

선수·팀 대표·심판 권한은 겸할 수 있다. 모든 등록 선수에게 내 선수 활동을 제공하고 주장·부주장은 팀 관리, 경기 일정 등록, 경기 결과 등록을 추가한다. 심판 가능 선수는 심판 활동 탭도 본다. 팀 대표 겸 심판은 다섯 탭을 모두 보지만 자기 팀 경기에는 심판을 맡을 수 없다.

심판의 중립성과 선수 자격은 경기 당시 소속 이력과 연결한다. 현재 팀으로 이적했다고 과거 경기 기록의 팀이나 심판 자격이 자동 변경되어서는 안 된다. 사전 등록 이후 소속 변동으로 심판이 참가 팀 소속이 되면 해당 배정의 적격성을 다시 확인하도록 설계한다.

흰 배경에 깔끔한 인상을 기본으로 한다. 한국어를 기본으로 하고 모바일에서도 경기 등록과 체크박스 복수 선택, 확인·승인이 가능해야 한다. 상태와 오류를 색상만으로 구분하지 않고, 제출 중 상태·중복 제출 방지·빈 목록 안내를 제공한다. 개인 득점 상위 기록 공개는 요청되었으며, 전체 경기 출전 명단과 그 밖의 개인 기록 공개 범위는 별도로 확정한다. 세부 UI/UX 요구와 시안 가정은 [UI와 UX 기획](UI_UX.md)을 따른다.

공개 팀·선수 디렉터리는 들어갈 때마다 무작위 순서로 표시한다. 선수 필터 변경이나 카드 상태 갱신 중에는 방문 당시 순서를 유지한다. 랭킹보드의 Elo 순위와 명단·권한 데이터는 영향을 받지 않는다. 페이지네이션 도입 시에도 방문 단위 순서를 유지해 중복·누락을 막는다.

## 인수 기준

실제 서비스를 구현한 뒤 다음 항목을 검증한다. 지금 문서 작업 단계에서는 테스트 코드나 웹 앱을 작성하지 않는다.

1. 학교 이메일 미인증 사용자는 선수 등록을 완료할 수 없고, 인증과 필수 정보 입력을 마친 사용자는 운영진 승인 없이 등록된다.
2. 교직원은 사번·지도교수 해당 없음으로 등록할 수 있다. 타 학과 대학원생의 GSDS·ISE 지도교수 자격을 입력할 수 있다.
3. 팀이 없는 선수도 정상 등록된다. 동시 가입 요청에도 두 팀의 활성 소속을 만들 수 없다.
4. 팀 등록 승인 시 6~20명과 주장·부주장 조건을 검사한다. 20명 초과와 인원 미달 상태의 공식 경기 등록을 서버에서도 차단한다.
5. 주장·부주장이 같은 팀 운영 권한을 갖고, 둘 중 한 명의 확인으로 그 팀의 확인이 완료된다. 상대 팀 확인을 대신할 수 없다.
6. 경기 사전 정보와 체크박스 명단을 저장·복원할 수 있고, 6명 이상의 경기 출전 명단도 기록할 수 있다.
7. 참가 팀 소속 선수의 심판 배정을 차단하고 내부 심판의 수락을 기록한다.
8. 양 팀 확인 전에는 최종 승인할 수 없다. 내부 심판 경기는 배정된 심판, 외부 심판 경기는 운영진만 최종 승인한다.
9. 기록 수정 시 이전 확인이 무효화되고, 이전 버전 승인 요청이 거절된다. 이견이 있는 경기는 자동 확정되지 않는다.
10. 정규시간 동점이면 승부차기 승자가 필요하고 승부차기 득점은 정규시간 기록에 섞이지 않는다.
11. 확정 경기만 Elo에 반영되고 점수 차가 계산 결과에 영향을 주지 않는다. 중복·동시 확정 요청에도 한 번만 반영된다.
12. 다른 이용자의 랭킹 화면에서도 확정 결과를 수신하고, 재연결 시 최신 공식 상태를 복원한다.
13. 비회원·다른 선수·팀 대표·심판이 타인의 이메일·학번/사번·지도교수를 API나 실시간 구독으로 조회할 수 없다. 팀 상세에서는 이름과 연구실을 볼 수 있다.
14. 가입·로그인 OTP 인증·확정된 운영진 알림·내부 심판 후보 요청 외 메일을 임의로 추가하지 않는다. 링크 열람만으로 수락·승인하지 않는다.
15. 심판비 안내는 팀별 10,000원 직접 지급으로 표시되고 결제·운영진 정산 기능은 없다.
16. 과거 소속과 확정 기록을 현재 명단 수정으로 덮어쓰지 않는다. 운영진 정정은 이력과 Elo 정합성을 유지한다.
17. 처음 진입하면 소개 홈을 보여주고 랭킹보드로 이동할 수 있다. 랭킹보드는 전체 팀 순위와 제한된 개인 득점·심판 공로 기록을 제공한다.
18. 팀 카드에서 팀 상세로 이동해 모든 팀원의 이름·연구실을 볼 수 있다. 선수 목록의 소속·무소속 필터가 실제 소속 상태와 일치한다.
19. 모집 중인 팀에 주황색 배지가 표시된다. 무소속 등록 선수가 팀 대표에게 홈페이지 내 문의·가입 요청을 할 수 있고 요청만으로 팀 소속이 바뀌지 않는다.
20. 심판 가능 표시가 공개 선수 카드와 필터에 일치한다. 전체·팀 소속·무소속·심판을 같은 모양의 단일 선택 버튼으로 제공하고 심판은 소속과 무관하게 심판 가능한 선수를 표시한다.
21. 팀 대표 이미지가 없으면 기본 이미지를 표시하고, 주장·부주장의 팀 프로필 업로드가 팀 카드·상세에 반영된다. 방출은 대상 이름이 있는 확인 팝업을 거치며 취소 시 소속이 유지된다.
22. 대표는 자기 팀 명단·득점만 수정할 수 있다. 양 팀 스코어 불일치 시 최종 승인과 Elo 반영을 차단하고 운영진 알림·검토 항목을 생성한다. 동일 팀 순서와 승부차기까지 대조한다.
23. 팀·선수 디렉터리는 재진입 시 무작위 순서를 사용하고 필터 중에는 순서를 유지하며 랭킹보드는 순위를 유지한다.
24. 인증번호는 숫자 6자리이며 발급 후 5분 만료·재발급 무효화·일회 사용·이메일 귀속을 서버에서 검증한다. 미동의 가입은 차단하고 확정된 개인정보 안내·동의 버전을 기록한다.
25. 심판 겸 선수는 내 선수 활동·심판 활동을 모두 보고 주장·부주장은 내 선수 활동 포함 네 탭, 심판도 겸하면 다섯 탭을 본다.
26. 적격 심판 후보를 여러 명 선택해 각자 요청 이메일을 보낼 수 있다. 동시 수락과 중복 요청에도 한 명만 배정되고 다른 요청은 종료된다. 배정 전 공식 등록을 보류하며 늦은 수락·무효한 요청 버전은 배정을 변경하지 못한다.
27. OTP 로그인·서버 세션·로그아웃을 제공한다. 팀 탈퇴는 확인 취소 시 변화 없고 확인 시 대표 승인 없이 즉시 무소속이며 과거 기록은 유지된다. 별도 이적 승인 기능은 없다.
28. 대표 교체는 운영진 승인 전·후 권한이 구분되고 탈퇴한 후보에게 승인할 수 없다. 6명 미만은 유예·충원 복귀·기한 만료 제외로 처리하며 즉시 퇴출·기록 삭제하지 않는다.
