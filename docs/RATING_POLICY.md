# IGFL Elo와 개인 기록 기본 규칙

2026-10-19 최신 결정: [프리시즌 규칙](PRESEASON.md)을 확정했다. 프리시즌에 한해 5·6대6, 전후반 15·20분, 심판 없는 경기를 허용하며 무심판 결과는 양 팀 대표의 같은 버전 확인으로 자동 확정한다. 기록은 정규리그와 분리하고 정규리그 Elo는 1000에서 새로 시작한다. 기간은 2027년 봄학기 개강 전까지이며 정확한 종료일은 추후 공지한다. 아래 심판 1명·5대5·20분 기본 규칙은 정규리그 기준이다. 실제 가입·시즌·리그 자동 메일은 계속 닫는다.

사용자가 무난한 Elo와 개인 기록 집계 방식을 맡긴 데 따라 2026년 10월 16일 다음 기본값을 채택한다. 특정 국제연맹 규정을 그대로 도입하는 것이 아니라 IGFL의 단순한 운영 규칙이다. 시즌 일정·대회 진출 동률 규칙·시즌 이월은 아직 미정이다.

## 팀 Elo

| 항목 | 적용값 |
| --- | --- |
| 신규 팀 초기 점수 | 1000 |
| K값 | 모든 공식 자율 경기에서 32 |
| 기대 승률 척도 | 400 |
| 경기 결과 S | 최종 승리 1, 패배 0 |
| 승부차기 | 승자 1·패자 0으로 동일 처리 |
| 점수 차·홈 이점·연승 가중치 | 반영하지 않음 |
| 반영 대상 | 양 팀 확인·스코어 일치와 최종 승인을 마친 공식 확정 경기 |

```text
E_A = 1 / (1 + 10 ^ ((R_B - R_A) / 400))
E_B = 1 - E_A
R_A_new = R_A + 32 × (S_A - E_A)
R_B_new = R_B + 32 × (S_B - E_B)
```

양 팀의 경기 전 점수로 두 팀 점수를 함께 계산한다. 같은 1000점 팀끼리 경기하면 승자는 1016점, 패자는 984점이다. 1점 차와 10점 차 승리는 같은 점수 변화를 만든다. 승부차기 승리도 같은 방식이다.

경기 일시순으로 계산하며 같은 일시는 안정적인 경기 ID 순서를 사용한다. 정정되거나 늦게 확정된 과거 경기가 있으면 해당 순서부터 뒤의 경기를 다시 계산한다. 한 시즌 계산 중에는 신규 경기 반영·정정이 서로 충돌하지 않게 처리한다. 유예·리그 제외 전 확정된 경기의 결과를 팀 상태만 바뀌었다고 없애지 않는다.

저장은 정밀도를 유지하고 표시만 정수로 반올림한다. 다음 계산에 화면의 반올림값을 사용하지 않는다. 공식 순위는 저장된 점수를 기준으로 하고 정확히 동률이면 공동순위로 표시한다. 공동순위 안의 표시 순서는 팀 이름·ID로 안정화하며 토너먼트 진출의 타이브레이커로 사용하지 않는다.

프리시즌에서 첫 정규리그로 넘어갈 때는 Elo를 이월하지 않고 1000에서 새로 시작한다. 이후 정규시즌 간 이월, 컵·토너먼트 Elo, 반복 상대·최소 경기 수 제한은 미정이다. 현 시즌 공식 결과 계산은 위 규칙으로 구현한다.

## 개인 득점

- 현 시즌에 각 선수가 실제 출전한 공식 확정 경기 중 최근 **5경기**를 집계한다.
- 경기 일시·경기 ID로 최근 순서를 결정한다. 팀 이동으로 같은 선수의 현 시즌 기록을 초기화하지 않는다.
- 5경기 미만이면 실제 출전 경기만 집계하고 경기 수를 함께 표시한다. 추가 최소 출전 제한은 두지 않는다.
- 정규시간 선수 득점만 합산한다. 승부차기 골은 제외한다.
- 득점 수 내림차순 **상위 3위**를 표시한다. 동률은 공동순위이며 3위의 동률 선수를 함께 보여주므로 카드가 3개를 넘을 수 있다. 예: 1·1·3위.
- 동률 내 나열은 이름·내부 ID로 안정화하고 실력 차이를 의미하는 별도 순위는 부여하지 않는다.
- 0골 선수로 빈 순위를 채우지 않는다. 득점 기록이 없으면 빈 상태를 표시한다.

외부 심판은 선수 등록 없이 가능하므로 개인 득점의 등록 선수와 혼합하지 않는다. 탈퇴·삭제 시 과거 이름 표시 정책은 개인정보 정책 확정 뒤 적용한다.

## 심판 공로

현 시즌 공식 확정 경기에서 실제 담당한 **내부 심판**의 경기 수를 합산해 상위 3위를 표시한다. 요청·수락만 한 경기, 취소 경기와 아직 확정되지 않은 경기는 제외한다. 동률은 개인 득점과 같이 공동순위와 경계 동률 전원 표시를 적용한다. 기록이 없으면 가짜 인물로 채우지 않는다.

외부 심판은 계정·공개 이름 동의 문제가 있으므로 기본 공로 보드에서는 제외한다. 외부 심판을 제외한다고 공식 경기 기록이나 지급 대상에서 제외하는 것은 아니다.

## 검증 예시

1. 동점수 팀의 승패 변화가 각각 +16·-16인지 확인한다.
2. 두 팀이 동일한 경기 전 점수를 사용하며 두 팀 변화량 합계가 수치 오차 범위에서 0인지 확인한다.
3. 점수 차·승부차기 여부만 바꿔도 최종 승패가 같으면 Elo가 같은지 확인한다.
4. 미확정·불일치·이의 검토 경기가 반영되지 않는지 확인한다.
5. 중복 확정, 과거 경기 지연 확정과 정정 재계산이 같은 최종 순위를 만드는지 확인한다.
6. 개인별로 서로 다른 출전 경기 5개를 집계하며 정규시간·승부차기 득점을 구분하는지 확인한다.
7. 동률과 출전 5경기 미만·0골·심판 미확정 경기의 표시를 확인한다.
