# IGFL 개인정보 처리 및 가입 동의 초안

2026-10-16 검토안. 예상 선수 100명·팀 10개 규모다. 아래 보관 기간·탈퇴 처리·공개 동의 방식은 사용자 검토 전의 제안이며 아직 가입 화면이나 실제 파기 작업에 적용하지 않았다. 선수 등록은 계속 닫아둔다. 운영 문의 주소와 Google 소유 계정은 사용자가 지정했으며 실제 값은 공개 저장소에 넣지 않는다. 시즌 날짜는 미정이다.

## 권장 보관 기간

회원 탈퇴와 팀 탈퇴를 구분한다. 팀 탈퇴는 즉시 무소속 전환이며 회원·개인 기록을 유지한다. 회원 탈퇴는 로그인 계정과 개인 식별 정보를 삭제하는 별도 기능이다.

| 구분 | 권장 보유 기간과 종료 처리 |
| --- | --- |
| 회원 기본 정보·자격 정보 | 회원 유지 중. 회원 탈퇴·동의 철회·서비스 종료 중 먼저 발생한 시점에 지체 없이 삭제 |
| 실명·연구실이 붙은 개인 경기·득점·심판 기록 | 회원 유지 중이며 해당 시즌 종료 후 2년 이내. 탈퇴·공개 동의 철회 시 공개를 즉시 중단하고 해당 개인 연결도 삭제. 시즌 종료일을 정한 뒤 만료 시각 계산 |
| 인증번호 검증값·발송 제한 정보 | 번호는 5분 유효·일회용. 사용/만료 후 불필요한 검증값은 삭제하고 남용 방지에 필요한 최소 정보만 발급 후 24시간 이내 유지 |
| 로그인 세션 | 최대 12시간. 로그아웃·탈퇴 시 즉시 무효화하고 불필요한 서버 기록 삭제 |
| 최소 운영·보안 로그 | 발생 후 90일을 상한으로 제안. 전체 프로필·메일 본문을 복사하지 않는다. 탈퇴 시 연결 식별자도 제거하며 별도 보유 근거 없이 이메일·학번을 남기지 않는다 |
| 팀 대 팀 결과·승패·Elo | 리그 아카이브 운영 중 유지. 탈퇴자 개인을 식별하거나 재연결할 수 없는 팀 단위 기록만 해당 |

이 기간들은 법에서 IGFL에 일률적으로 요구하는 기간이 아니다. 목적 달성·보유 기간 경과 후에는 지체 없이 파기하는 것이 원칙이다. 분쟁이 있다는 이유만으로 탈퇴자의 전체 정보를 계속 보관하지 않는다. 별도 근거가 있는 사건 자료만 목적·항목·종료일을 따로 정한다. [개인정보 보호법 제21조](https://www.law.go.kr/법령/개인정보보호법/제21조).

생년월일은 참가 자격·경기 운영에 필요한 용도가 현재 없으므로 **수집 항목에서 제외하는 것을 권장**한다. 학번/사번은 중복·자격 확인에만 사용하고 공개하지 않는다. 향후 이메일만으로 충분하다고 판단되면 이 항목도 축소한다. 기존 가입 폼에는 생년월일이 남아 있으므로 정책 확정 후 함께 변경해야 한다. [최소 수집 원칙](https://www.law.go.kr/법령/개인정보보호법/제16조).

## 회원 탈퇴 처리

1. 회원 탈퇴 확인 팝업에서 팀 탈퇴와 차이를 설명한다. 확인 즉시 계정 접근·모든 세션을 차단하고 선수 공개 카드·개인 보드 노출과 심판 후보 요청을 중단한다.
2. 이름·이메일·학번/사번·생년월일·학과·연구실·지도교수·자격 신고·심판 가능 여부·소속·대표 권한·가입 문의와 관련 개인 식별자를 삭제한다. 대표 공석·미배정 심판이 생기면 운영진에게 홈페이지 알림을 남긴다. 팀 정원·유예 규칙은 기존 규칙을 적용한다.
3. 예정 명단·실제 명단·득점자·심판 기록·확인자·감사 로그·메일 작업·이전 스냅샷에 복사된 정보와 개인 연결 키를 함께 제거한다. 팀의 결과·스코어·최종 승자·경기 날짜·Elo는 유지한다.
4. 개인 표시가 꼭 필요한 과거 화면에는 공통 문구 `탈퇴 선수`만 사용하고 프로필 링크·연구실·동일인을 추적하는 공개 ID는 제공하지 않는다. 내부 ID·날짜·명단 등으로 다시 식별할 수 있다면 익명 정보라고 주장하지 않고 삭제 범위를 더 넓힌다.
5. 지체 없는 파기를 기본으로 하며, 운영 처리 완료 안내 목표를 영업일 5일 이내로 둔다. 이 목표는 5일간 일괄 보관해도 된다는 뜻이 아니다. 예외가 있으면 항목·근거·기간을 본인에게 알린다.

득점자 삭제로 과거 상세 득점 합계와 팀 스코어가 달라져도 팀 스코어는 바꾸지 않는다. 이미 확정한 경기의 승패와 Elo를 탈퇴 때문에 다시 계산하지 않는다. 탈퇴자의 개인 순위와 심판 공로 노출은 제거한다. 재가입은 새 회원으로 처리하고 삭제한 과거 기록을 이메일 해시로 자동 복원하지 않는다.

백업과 Google Sheets의 변경 이력도 삭제 범위 검증에 포함한다. 단순히 최신 행만 지우거나 백업을 30일 뒤 순환 삭제하는 방식만으로 탈퇴 처리를 완료했다고 안내하지 않는다. 복구 시 삭제된 회원이 되살아나지 않도록 절차를 마련한다. 항목별 파기·복구 방지가 불가능한 저장 구조라면 실제 모집 전에 변경한다.

## 공개 범위 제안

기존 확정안은 공개 팀·선수 목록에서 실명과 연구실을 표시한다. 이번 검토안은 이 공개를 가입 수집 동의와 분리하고, 비동의자는 공개 선수번호로 표시하는 방식을 권장한다. 이 대안은 **아직 승인·구현되지 않았다**. 실명·연구실의 전체 인터넷 공개를 필수로 유지할지는 별도 결정해야 한다.

공개에 동의해도 이메일·학번/사번·생년월일·지도교수·개인 문의 내용은 공개하지 않는다. 본인과 운영진만 원본 개인정보를 열람한다. 팀 대표·배정 심판은 경기 운영에 필요한 명단과 기록만 확인한다. 전체 경기 명단·개별 경기 상세의 인터넷 공개는 이번 초안에서 확대하지 않는다.

## 가입 화면 문구 초안

아래 문구는 생년월일 수집 제외와 선택적 공개 대안을 채택할 때의 초안이다. 체크박스는 미리 선택하지 않고 문구 전문·버전·확인 시각을 기록한다. 필수 수집 동의와 공개·심판 선택 항목을 한 체크박스로 묶지 않는다. 동의에는 목적·항목·기간·거부 권리와 제한을 구체적으로 알린다. [개인정보 보호법 제15조](https://www.law.go.kr/법령/개인정보보호법/제15조).

### 필수 개인정보 수집 및 이용 동의

> IGFL 운영진은 회원 확인, 참가 자격 및 중복 등록 확인, 팀·경기 운영, 기록 확인과 문의 처리를 위해 이름, KAIST 이메일, 학번 또는 사번, 참가 자격 구분, 소속 학과·부서, 소속 연구실, 지도교수 정보(해당자), 팀 소속 및 경기·확인 기록을 수집·이용합니다. 연구실이 없는 교직원은 ‘해당 없음’으로 입력할 수 있습니다.
>
> 회원 기본 정보는 회원 탈퇴·동의 철회·서비스 종료까지 보유하며 해당 사유가 발생하면 지체 없이 파기합니다. 개인과 연결된 시즌 기록은 회원 유지 중에만 보유하고 시즌 종료 후 최대 2년 이내 삭제합니다. 개인을 식별할 수 없는 팀 경기 결과와 Elo는 리그 기록으로 보존할 수 있습니다.
>
> 동의를 거부할 수 있으나, 참가자 확인과 경기 운영에 필요한 필수 정보에 동의하지 않으면 선수 등록과 회원 기능 이용이 제한됩니다. 문의·열람·정정·삭제·탈퇴 요청: [운영 문의 이메일].

### 선택 실명 프로필 및 개인 기록 공개 동의

> IGFL 홈페이지 방문자에게 이름, 소속 연구실, 소속 팀·대표 역할, 득점 및 심판 활동 집계 기록을 공개하여 팀 소개와 리그 기록을 제공합니다. 회원 유지 중이며 해당 시즌 종료 후 최대 2년 이내 공개하고, 회원 탈퇴 또는 공개 동의 철회 시 공개를 중단합니다. 인터넷 공개 정보는 방문자가 별도로 복사할 수 있어 운영진이 외부 사본까지 회수할 수는 없습니다.
>
> 공개 동의를 거부하거나 철회할 수 있으며 이 경우 공개 화면에는 선수번호를 표시하고 실명·연구실과 실명 개인 순위는 노출하지 않습니다. 리그 참가 자체에는 영향을 주지 않습니다. 운영에 필요한 명단 확인은 필수 수집·이용 범위에서 처리합니다.
>
> ☐ [선택] 실명 프로필 및 개인 기록 공개에 동의합니다.

### 선택 심판 활동 신청

> ☐ 심판 활동을 신청합니다. 양 팀 소속이 아닌 경기의 심판 후보로 표시되며 배정 요청 이메일을 받을 수 있습니다. 심판비는 경기당 20,000원이고 각 팀이 10,000원씩 심판에게 직접 지급합니다. 신청하지 않아도 선수로 참가할 수 있고 내 활동에서 변경할 수 있습니다. 공개 카드의 ‘선수 / 심판’ 표시는 공개 동의 범위에 따릅니다.

### 최초 이메일 인증 화면의 짧은 안내

> 로그인·이메일 확인을 위해 KAIST 이메일과 인증 요청 정보를 처리합니다. 인증번호는 5분 동안 유효하며, 남용 방지를 위한 최소 인증 요청 정보는 최대 24시간 보관합니다. 선수 프로필은 별도의 가입 동의 후 등록합니다. [개인정보 처리방침 보기] · 문의 [운영 문의 이메일]

이 문구를 넣는 것만으로 실제 저장·정리 방식이 완성되는 것은 아니다. 현재 요청이 없을 때도 인증 기록을 만료 정리하는 작업을 추가해야 한다.

## Google 서비스 이용 안내의 확정 필요 항목

인증·메일·데이터 저장에 Apps Script, MailApp, 비공개 Google Sheets를 사용한다. Google 계정 운영 가능 여부와 학교 계정을 리그 개인정보 처리에 사용해도 되는지는 별개다. Workspace 계약 주체·처리 수탁자·연락처·실제 처리/보관 국가·항목·방법·기간을 확인해 처리방침에 반영한다. 확인하지 않은 국가를 ‘미국만’이라고 쓰지 않는다.

국외 이전에 해당하면 적용 가능한 근거와 필요한 안내를 정해야 한다. 별도 동의를 근거로 삼는 경우 이전 항목, 국가·시기·방법, 수령자와 연락처, 목적·기간, 거부 방법과 효과를 채운 별도 문구가 필요하다. 단순히 ‘Google 사용에 동의’라는 문장으로 대체하지 않는다. [개인정보 보호법 제28조의8](https://www.law.go.kr/법령/개인정보보호법/제28조의8).

## 수집 개통 전 구현 사항

- 현재 서버에는 회원 탈퇴·개인 연결 삭제·공개 동의 철회·보관 기간 정리 기능이 없다. 팀 탈퇴는 회원 탈퇴를 대신하지 않는다.
- `LeagueSnapshots`는 이전 전체 상태를 계속 추가하므로 최신 상태 삭제만으로는 과거 개인정보가 제거되지 않는다. 개인정보 원본과 경기 이력을 분리하고 과거 복사본까지 파기 가능한 저장 방식을 검증한다.
- 동의 버전·공개 여부·철회 시각과 서버의 공개 투영을 함께 구현한다. 개인정보를 모두 내려받은 뒤 브라우저에서 가리지 않는다.
- 실명·연구실 비공개 대안을 채택하면 카드·팀 상세·득점·심판 보드·이미지·팀 소개의 자유 입력에도 동일 정책을 적용한다.
- 정리 스케줄러, 메일 작업함과 감사 로그의 최소화, 삭제 후 복구 시험을 합성 데이터로 검증한다. Google 시트의 이전 버전까지 검증하기 전 완전 삭제를 보장한다고 안내하지 않는다.
- 최종 처리방침·문의 창구·필수/선택 동의를 반영하고 검증한 뒤 `PRIVACY_VERSION`, `PRIVACY_NOTICE`, 가입 개통 여부를 별도로 정한다.
