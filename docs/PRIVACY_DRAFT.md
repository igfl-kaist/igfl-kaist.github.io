# IGFL 개인정보 처리 및 가입 동의

2026-10-16 사용자 결정 반영. 예상 선수 100명·팀 10개. 생년월일은 수집하지 않으며 이름·연구실 및 리그 기록의 공개 동의를 별도 필수 항목으로 받는다. 아래 보관·탈퇴·과거 기록 정책을 채택했다. 실제 선수 등록은 사용자 지시로 계속 닫아둔다. Google 처리 세부 고지와 변경 이력·백업 파기 검증은 개통 전에 완료한다. 운영 문의 주소와 Google 소유 계정은 사용자가 지정했으며 실제 값은 공개 저장소에 넣지 않는다. 시즌 날짜는 미정이다.

## 보관 기간

회원 탈퇴와 팀 탈퇴를 구분한다. 팀 탈퇴는 즉시 무소속 전환이며 회원·개인 기록을 유지한다. 회원 탈퇴는 로그인 계정과 개인 식별 정보를 삭제하는 별도 기능이다.

| 구분 | 보유 기간과 종료 처리 |
| --- | --- |
| 회원 기본 정보·자격 정보 | 회원 유지 중. 회원 탈퇴·동의 철회·서비스 종료 중 먼저 발생한 시점에 지체 없이 삭제 |
| 실명·연구실이 붙은 개인 경기·득점·심판 기록 | 회원 유지 중이며 해당 시즌 종료 후 2년 이내. 탈퇴·공개 동의 철회 시 공개를 즉시 중단하고 해당 개인 연결도 삭제. 시즌 종료일을 정한 뒤 만료 시각 계산 |
| 인증번호 검증값·발송 제한 정보 | 번호는 5분 유효·일회용. 사용/만료 후 불필요한 검증값은 삭제하고 남용 방지에 필요한 최소 정보만 발급 후 24시간 이내 유지 |
| 로그인 세션 | 최대 12시간. 로그아웃·탈퇴 시 즉시 무효화하고 불필요한 서버 기록 삭제 |
| 최소 운영·보안 로그 | 발생 후 90일을 상한으로 적용. 전체 프로필·메일 본문을 복사하지 않는다. 탈퇴 시 연결 식별자도 제거하며 별도 보유 근거 없이 이메일·학번을 남기지 않는다 |
| 팀 대 팀 결과·승패·Elo | 리그 아카이브 운영 중 유지. 탈퇴자 개인을 식별하거나 재연결할 수 없는 팀 단위 기록만 해당 |

이 기간들은 법에서 IGFL에 일률적으로 요구하는 기간이 아니다. 목적 달성·보유 기간 경과 후에는 지체 없이 파기하는 것이 원칙이다. 분쟁이 있다는 이유만으로 탈퇴자의 전체 정보를 계속 보관하지 않는다. 별도 근거가 있는 사건 자료만 목적·항목·종료일을 따로 정한다. [개인정보 보호법 제21조](https://www.law.go.kr/법령/개인정보보호법/제21조).

생년월일은 수집·저장·표시하지 않는다. 이전 개발 데이터의 생년월일도 마이그레이션에서 제거한다. 학번/사번은 중복·자격 확인에만 사용하고 공개하지 않는다. [최소 수집 원칙](https://www.law.go.kr/법령/개인정보보호법/제16조).

## 회원 탈퇴 처리

1. 회원 탈퇴 확인 팝업에서 팀 탈퇴와 차이를 설명한다. 확인 즉시 계정 접근·모든 세션을 차단하고 선수 공개 카드·개인 보드 노출과 심판 후보 요청을 중단한다.
2. 이름·이메일·학번/사번·학과·연구실·지도교수·자격 신고·심판 가능 여부·소속·대표 권한·가입 문의와 관련 개인 식별자를 삭제한다. 대표 공석·미배정 심판이 생기면 운영진에게 홈페이지 알림을 남긴다. 팀 정원·유예 규칙은 기존 규칙을 적용한다.
3. 예정 명단·실제 명단·득점자·심판 기록·확인자·감사 로그·메일 작업·이전 스냅샷에 복사된 정보와 개인 연결 키를 함께 제거한다. 팀의 결과·스코어·최종 승자·경기 날짜·Elo는 유지한다.
4. 개인 표시가 꼭 필요한 과거 화면에는 공통 문구 `탈퇴 선수`만 사용하고 프로필 링크·연구실·동일인을 추적하는 공개 ID는 제공하지 않는다. 내부 ID·날짜·명단 등으로 다시 식별할 수 있다면 익명 정보라고 주장하지 않고 삭제 범위를 더 넓힌다.
5. 지체 없는 파기를 기본으로 하며, 운영 처리 완료 안내 목표를 영업일 5일 이내로 둔다. 이 목표는 5일간 일괄 보관해도 된다는 뜻이 아니다. 예외가 있으면 항목·근거·기간을 본인에게 알린다.

득점자 삭제로 과거 상세 득점 합계와 팀 스코어가 달라져도 팀 스코어는 바꾸지 않는다. 이미 확정한 경기의 승패와 Elo를 탈퇴 때문에 다시 계산하지 않는다. 탈퇴자의 개인 순위와 심판 공로 노출은 제거한다. 재가입은 새 회원으로 처리하고 삭제한 과거 기록을 이메일 해시로 자동 복원하지 않는다.

백업과 Google Sheets의 변경 이력도 삭제 범위 검증에 포함한다. 단순히 최신 행만 지우거나 백업을 30일 뒤 순환 삭제하는 방식만으로 탈퇴 처리를 완료했다고 안내하지 않는다. 복구 시 삭제된 회원이 되살아나지 않도록 절차를 마련한다. 항목별 파기·복구 방지가 불가능한 저장 구조라면 실제 모집 전에 변경한다.

## 필수 공개 동의

가입 시 개인정보 수집·이용과 이름·연구실 및 리그 기록 공개에 대해 각각 필수 동의를 받는다. 공개 동의를 거부하면 선수 등록을 완료할 수 없다. 선수번호·익명 가입 대안은 채택하지 않았다. 두 체크박스는 미리 선택하지 않고 서버가 두 동의 버전과 시각을 각각 기록한다.

이메일·학번/사번·지도교수·개인 문의는 공개하지 않는다. 본인과 운영진만 원본 개인정보를 열람한다. 팀 대표와 배정 심판은 경기 운영에 필요한 명단과 기록만 확인한다. 전체 경기 상세의 인터넷 공개는 확대하지 않는다. 공개 동의 철회는 회원 탈퇴와 같은 개인 연결 삭제 절차로 처리한다.

## Google 서비스 이용 안내의 확정 필요 항목

인증·메일·데이터 저장에 Apps Script, MailApp, 비공개 Google Sheets를 사용한다. Google 계정 운영 가능 여부와 학교 계정을 리그 개인정보 처리에 사용해도 되는지는 별개다. Workspace 계약 주체·처리 수탁자·연락처·실제 처리/보관 국가·항목·방법·기간을 확인해 처리방침에 반영한다. 확인하지 않은 국가를 ‘미국만’이라고 쓰지 않는다.

국외 이전에 해당하면 적용 가능한 근거와 필요한 안내를 정해야 한다. 별도 동의를 근거로 삼는 경우 이전 항목, 국가·시기·방법, 수령자와 연락처, 목적·기간, 거부 방법과 효과를 채운 별도 문구가 필요하다. 단순히 ‘Google 사용에 동의’라는 문장으로 대체하지 않는다. [개인정보 보호법 제28조의8](https://www.law.go.kr/법령/개인정보보호법/제28조의8).

## 구현 상태와 개통 전 검증

- 회원 탈퇴 확인 팝업, 계정·개인 연결 삭제, 공개 보드 제외, 대표 권한 해제, 모든 로그인 세션 폐기와 재가입 시 새 내부 ID 발급을 구현했다. 팀 탈퇴는 별도 기능으로 유지한다.
- 탈퇴 처리 중 실패하면 비공개 작업 표시를 남기고 다음 리그 요청 또는 정리 작업에서 재시도한다. 완료 전 해당 계정의 새 로그인 세션을 차단한다.
- 앱의 이전 전체 스냅샷은 최신 상태를 먼저 확정한 뒤 정리한다. 이 작업은 Google Sheets 자체 변경 이력이나 외부 사본을 삭제했다는 증명이 아니다. **Google 변경 이력·백업·이미지와 자유 입력의 개인 식별 정보까지 파기·복구 방지를 검증하기 전 실제 선수 수집을 열지 않는다.**
- `runPrivacyMaintenance()`에 인증 기록·미등록 계정·90일 운영 로그·시즌 종료 후 2년 개인 기록 정리를 연결했다. 시간 기반 트리거·별도 Google 합성 시트 검증을 진행했고 결과는 [삭제 검증](PRIVACY_VERIFICATION.md)에 남긴다. 현재 셀의 주기적 정리는 Google 자체 변경 이력 파기를 뜻하지 않는다.
- 종료 날짜는 `LEAGUE_SEASON_ENDS_AT`에 넣고 시즌별 종료일을 이력에 보존한다. 시즌 날짜 미정 상태에서 임의의 종료일을 적용하지 않는다.
- 운영 연락처의 실제 값은 비공개 설정으로 관리한다. Google 수탁·국외 이전 고지, 자동 정리, 삭제 후 복구 시험을 완료하고 운영자 지시가 있을 때만 가입을 개통한다.

## 2026-10-18 저장소 검토

Google Sheets의 개별 변경 이력 삭제는 지원되지 않음을 확인했다. 현재 평문 Sheets 저장 구조를 그대로 사용해 회원별 파기를 완료했다고 안내할 수 없어 `PRIVACY_STORAGE_APPROVED`를 미승인으로 유지한다. 실제 가입 스위치만 변경해도 개통되지 않는다. Google 관리자 복구·Vault 보관과 원시 백업 복원의 개인정보 재등장도 해소해야 한다. 자세한 근거·시험·재현 방법은 [개인정보 삭제와 자동 정리 검증](PRIVACY_VERIFICATION.md)을 따른다.
