# 팀·선수 공개 샘플

2026-10-19 사용자 요청으로 팀 2개·선수 14명의 표시 전용 샘플을 제공한다. 팀별 6명과 무소속 2명이며 심판 예시는 3명이다. 모든 이름은 ‘샘플 선수’, 소속은 ‘가상 연구실’로 표시한다. 팀/선수 목록과 팀 상세에 샘플임을 명시하고 실제 등록 인원과 샘플 수를 따로 센다. 팀 하나에는 주황색 모집 표시 예시를 제공한다.

`src/directory-examples.mjs`의 공개 가상 데이터가 원본이다. 서버 공개 응답의 별도 `examples` 필드로 제공하며 **실제 `players`·`profiles`·`teams`·`memberships`·인증 Accounts에 삽입하지 않는다.** 이메일·학번·동의 기록·로그인 계정을 만들지 않는다. 실제 참가 팀/선수인 것처럼 소개하거나 랭킹·시즌 집계에 포함하지 않는다.

실제 팀 선택·등록 선수 영입·심판 후보·경기 상대는 기존 실제 배열만 사용한다. 표시 전용 샘플에 가입·영입·경기 요청을 보내는 UI를 제공하지 않는다. 위조한 샘플 ID 요청도 서버의 실제 컬렉션 조회/자격 검사에서 거절하며 `example-` 사용자 ID의 회원 명령도 거절한다. 단순 버튼 숨김에 의존하지 않는다.

소유자 `configureDirectoryExamples()`는 Script Property `LEAGUE_DIRECTORY_EXAMPLES=true`만 설정하고 진단을 출력한다. `disableDirectoryExamples()`는 false로 숨긴다. `inspectDirectoryExamples()`는 표시 여부와 샘플/실제 인원 수, 가입/시즌/자동 메일 상태만 조회한다. 실제 데이터·운영 포인터·인증·권한·가입 스위치·메일 설정을 바꾸거나 메일을 보내지 않는다. 샘플을 숨겨도 실제 회원과 과거 기록은 그대로다.

가입/저장소 승인 true, 시즌/자동 리그 메일 false, 인증 300회/24시간을 유지한다. 자동 검증 90개와 정적/GAS 빌드를 통과했다. 샘플 분리·집계 제외·위조 ID 거부·설정 반복/해제의 안전성을 포함한다. 브라우저에서 샘플 팀 목록과 상세 팀원 6명, 요청 양식 없음, 무소속 샘플 2명·심판 샘플 3명 필터를 확인했다. 실제 배포 결과는 [배포 기록](AUTH_DEPLOYMENT.md)에 추가한다.

2026-10-19 실제 적용 완료: Apps Script 버전 14/코드 0.6.1, 별도 공개 샘플 2팀/14명 표시와 기존 실제 회원 보존·시즌별 랭킹 제외를 확인했다. 배포 증거와 인원 확인 시점은 배포 기록을 따른다.
