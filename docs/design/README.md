# IGFL 승인 시안 안내

`igfl-approved-mockup.html`은 2026년 10월 16일 최신 수정사항을 반영한 디자인 시안 원본이다. 소개·랭킹·팀·선수, 6자리 인증·동의와 비밀번호 없는 이메일 OTP 로그인, 즉시 팀 탈퇴 팝업, 대표 교체 요청·승인, 인원 미달 유예와 복수 심판 요청을 포함한다. 모든 인명·팀·연구실·기록과 처리 결과는 합성 예시다.

구현 agent는 이 파일의 배치·색·문구·폼·상태 표현을 실제 앱의 디자인 기준으로 사용한다. 기능 요구는 [최종 구현 지침](../IMPLEMENTATION_BRIEF.md), 예시와 미정 사항의 구분은 [UI와 UX 기획](../UI_UX.md)과 [결정할 사항](../DECISIONS.md)을 따른다.

## 원본 형식

이 파일은 대화 내 디자인 검토용 HTML 조각이다. 완성된 독립 웹 앱이나 배포용 `index.html`이 아니다. 호스트가 제공하는 아이콘·디자인 조절·상태 저장 기능을 일부 사용하며, 일반 브라우저에서 파일 하나를 여는 것만으로 모든 요소가 동일하게 나타난다고 가정하지 않는다.

실제 서비스에서는 이를 선택한 프런트엔드의 컴포넌트와 스타일로 옮긴다. 대화 호스트 의존 기능, 역할 미리보기 선택기, 다른 이용자 행동을 대신 실행하는 시나리오 버튼, 화면에 표시하는 체험용 인증번호를 제거하고 실제 로그인·권한·API·영구 저장으로 대체한다. 원본 조각을 그대로 공개 배포하는 것으로 구현을 마치지 않는다.

## 확정하지 않은 예시

- 이메일 인증 오입력 5회 제한.
- 팀 이미지 JPG·PNG·WebP / 3MB 제한과 크롭 방식.
- 외부 심판 배정 수락을 팀 대표의 체크로 확인하는 방식.
- 일정 변경 시 기존 심판 요청·배정을 초기화하는 방식.
- 팀 유예의 정확한 기간은 60일 기본안이며 운영 설정으로 둔다.
- 합성 운영 목록과 시나리오 상태 전환.

이 값과 예시는 운영 확정값과 구분한다. 최근 출전 5경기·시즌 공식 내부 심판 상위 3위는 이제 채택한 기본 규칙이다. 6자리·5분, 팀 6~20명과 심판비 20,000원도 유지한다.

## 원본 확인

시안 내용은 사용자 대화의 최신 원본을 수정 없이 복사했다. 보관 시 SHA-256은 다음과 같다.

```text
16e7441634ac1bfb4dbc7996698888ae6c6b38f22df44e31826dca3a572239d1
```

시안만으로 선수 자격이나 운영 정책을 바꾸지 않는다. 변경 요청이 오면 해당 기획과 구현 지침도 함께 갱신한다.
