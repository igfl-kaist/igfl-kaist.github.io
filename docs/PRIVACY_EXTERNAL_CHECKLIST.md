# IGFL 학교와 Google 확인 목록

## 2026-10-19 최신 결정: 선수·팀 모집 시범 개통

사용자는 현재 정보 자동 정리·새 시트 검증 전환과 이전 파일/사본/휴지통의 운영자 수동 파기, 삭제 자료 복구 요청·복원 사용 금지 원칙으로 시범 운영을 시작하기로 했다. 선수 가입·팀 신청만 개통하고 경기 등록(`LEAGUE_SEASON_OPEN`)·리그 메일 자동 발송(`LEAGUE_EMAILS_ENABLED`)은 계속 닫는다. 인증은 24시간 전체 예약 300회, 이메일별 시간당 5회·60초 간격·코드 5분·세션 12시간을 유지한다. Google 실제 잔여 수신자 한도도 계속 강제한다.

`PRIVACY_STORAGE_APPROVED`는 이 수동 파기 시범 운영에 대한 운영자의 결정이며 학교·Google의 승인이나 법적 적합성·공급자 완전 파기 확인을 뜻하지 않는다. 외부 처리 주체·국가·복구/Vault/백업 세부 조건은 확인 중으로 남기고 이를 확인 완료로 기재하지 않는다. 공통 안내/동의는 2026-10-19 v3다. 자세한 절차는 [모집 개통 인계](RECRUITMENT_LAUNCH.md)를 따른다. 아래 이전 날짜의 가입 차단 기록은 당시 상태다.

2026-10-18 기준. 선수 약 100명·팀 약 10개 규모의 자율 풋살 리그를 운영하기 위해 학교 Google 계정으로 Apps Script 이메일 인증과 비공개 Sheets를 사용한다. 홈페이지의 개인정보 처리방침·가입 동의 안내는 게시하되, 아래 조건 확인과 최종 안내 반영 전까지 실제 선수 가입은 닫아둔다.

이 문서는 운영자가 학교 담당자·Google Workspace 관리자에게 확인할 질문이다. 확인 요청 메일을 대신 발송하지 않았다. 확인되지 않은 보관 국가·Google 계약 법인·삭제 완료 기간을 확정값으로 쓰지 않는다. 실제 서버 키·세션·파일 ID·회원 정보는 문의에 첨부하지 않는다.

## 학교 담당자에게 먼저 확인할 내용

우선 소속 학과 또는 연구실의 해당 Google 도메인 관리자에게 관리 주체를 확인하고, 필요하면 학교 개인정보 담당 부서에 연결을 요청한다. `comet.kaist.ac.kr`의 계약·관리 주체를 중앙 학교 계정과 동일하다고 가정하지 않는다.

| 확인할 사항 | 전달할 질문 | 확인 후 반영 |
| --- | --- | --- |
| 계정 사용 허용 | 연구실/학교에서 제공한 Google 계정을 학생 자율 리그의 이메일 인증과 회원 정보 보관에 사용해도 되는가? 별도 신고·승인이 필요한가? | 사용 허용 범위·승인 주체·조건 기록 |
| 운영 책임과 연락처 | 개인정보 처리 주체를 IGFL 운영진으로 두는 것이 적절한가? 학교가 처리 주체라면 어떤 부서·책임자·연락처를 표시해야 하는가? 현재 운영 문의 이메일만으로 충분한지, 추가 연락처가 필요한지? | 처리방침의 운영자·권리 요청 창구 최종화 |
| 수집·공개 범위 | 이름·학교 이메일·학번/사번·학과/부서·연구실·지도교수·참가 자격·팀/경기 기록의 수집과 이름·연구실·팀·역할·득점/심판 집계의 필수 공개 동의가 리그 목적에 적합한가? | 필수 항목·동의 문구·공개 범위 검토 |
| 계정 유지와 인계 | 졸업·소속 변경·운영자 교체 때 계정·Apps Script 배포·시트·트리거가 어떻게 유지/중단되는가? 비밀번호 공유 없이 인계할 수 있는 방식은? | 소유자·접근권한·업무 인계 절차 |
| 계정 보안 | 운영 계정에 요구되는 다중 인증·편집자 제한·외부 호출 허용 정책이 있는가? 소유자 실행 웹 앱의 익명 호출 배포를 허용하는가? | 필요한 계정 설정과 웹 앱 운영 조건 |

수집·이용 동의는 목적·항목·보유 기간·거부 권리와 제한을 구체적으로 고지하도록 구성했고, 처리방침은 권리 행사 방법과 운영 창구를 포함한다. 공개 동의의 필수성·처리 주체 등 실제 적용은 학교 담당자와 확인한다. [개인정보 보호법 제15조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033214947), [제30조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1032645945).

## Google Workspace 관리자에게 확인할 내용

학교 담당자가 계정 관리자가 아니라면 해당 도메인의 Workspace 관리자에게 연결을 요청한다. 관리자가 확인할 수 없는 계약·서비스 항목만 Google 지원에 문의한다. 새로운 유료 서비스나 플랜을 먼저 구매할 필요는 없다.

| 확인할 사항 | 전달할 질문 | 확인 후 반영 |
| --- | --- | --- |
| 계약과 서비스 범위 | 이 도메인은 어떤 Workspace 계약/에디션을 쓰는가? Sheets·Apps Script·Script Properties·MailApp 각각에 어떤 계약과 개인정보 처리 조건이 적용되는가? 계약상 처리 법인과 연락처는 무엇인가? | 처리 수탁/서비스 제공자 명칭·연락처·업무 범위 |
| 처리·보관 국가 | 각 서비스의 실제 저장·처리 국가와 하위 처리업체 범위는 무엇인가? 데이터 리전 설정이 Apps Script/Properties/메일과 메타데이터·로그·백업에도 적용되는가? | 국가·방법·목적·기간 등 국외 처리 고지. 한국 또는 미국만이라고 추정하지 않음 |
| 삭제와 관리자 복구 | Drive 영구 삭제 후 관리자 복구가 가능한 기간은? Script Properties 항목 삭제·로그·메일과 공급자 백업의 삭제/보관 주기는? 해당 계정에서 삭제 요청을 처리하는 절차는? | 파기 안내와 처리 완료 범위·시점 |
| Vault와 별도 백업 | 해당 계정/조직에 Vault 보관 규칙·hold, 메일 아카이브, 외부 백업, 데스크톱 동기화가 적용되는가? 보유 사유·기간·접근자와 삭제/예외 절차는? | 운영자 수동 삭제만으로 처리되지 않는 잔존 범위 |
| 복원 시 탈퇴자 재등장 | 기간 단위 복원·계정 복구 시 이미 탈퇴한 정보가 되살아날 수 있는가? 복원 전에 운영진에게 알리고 삭제 대상 재적용 전 서비스 접근을 막을 수 있는가? | 원시 복원 금지와 재파기·재검증 절차 |
| 메일과 로그 | 인증 메일의 발신 계정·발송 기록·내용이 어디에 얼마나 보관되는가? 자동 발송 예산과 스팸 제한, 실행 로그의 보관/접근 범위는? | 인증 안내·운영 예산·최소 로그 정책 |

Google은 사용자 휴지통 비우기 후 관리자의 Drive 복구가 가능한 기간을 25일로 안내하며, Vault 보관/hold가 적용되면 그보다 오래 검색·내보내기가 가능할 수 있다고 설명한다. 이것이 해당 학교 계정의 실제 설정을 확인한 결과는 아니다. [Google 관리자 복구 안내](https://knowledge.workspace.google.com/admin/drive/recover-deleted-files-and-folders-for-drive-users?hl=en).

국외 처리가 해당되면 학교 개인정보 담당자에게 위탁·제공·보관의 구분과 적용 근거, 추가로 필요한 고지·동의 방식을 함께 확인한다. 국외 이전 동의를 적용할 경우 법에서 정한 항목에는 국가·시기·방법, 이전받는 자와 연락처, 이용 목적·보유 기간, 거부 방법과 효과 등이 포함된다. [개인정보 보호법 제28조의8 제2항](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1033215841). 일반 서비스 소개만으로 이 계정의 계약 범위를 확정하지 않는다.

## 문의에 붙일 서비스 설명

> ISE·GSDS 구성원과 해당 학과 교수의 지도를 받는 대학원생이 참여하는 자율 풋살 리그 IGFL을 준비하고 있습니다. 예상 선수는 약 100명, 팀은 약 10개이며 아직 실제 선수 가입은 닫혀 있습니다.
>
> 공개 홈페이지는 GitHub Pages에서 제공하고, 학교/연구실 Google 계정의 Apps Script로 학교 이메일 6자리 인증·로그인과 리그 서버를 운영하려고 합니다. 인증 요청·세션의 검증값과 계정 매핑은 Script Properties에, 선수·팀·경기 데이터는 소유자 전용 비공개 Sheets에 보관합니다. 비밀번호·생년월일·주민등록번호·계좌번호는 받지 않습니다.
>
> 선수 가입 시 개인정보 수집·이용과 이름·연구실 및 리그 집계 기록 공개를 각각 필수 동의로 받을 계획입니다. 이메일·학번/사번·지도교수·비공개 문의는 일반 방문자나 팀 대표에게 공개하지 않습니다.
>
> 탈퇴 시 인증 접근과 공개를 중단하고 현재 데이터를 정리한 새 시트를 검증해 전환합니다. 이전 파일·사본·휴지통은 운영자가 직접 파기하며 원시 백업 복원은 하지 않습니다. 계정의 사용 허용 범위, 적용 계약·보관 국가, 관리자 복구/Vault/별도 백업과 운영자 인계 조건을 확인받고 싶습니다.

## 답변을 받은 뒤 기록할 사항

답변 일자·담당 부서/역할·적용 서비스·근거 문서·허용 조건을 기록하고, 확인 중인 항목은 그대로 남긴다. 담당자의 개인 연락처나 비공개 계약서는 공개 저장소 대신 운영자가 관리하는 비공개 자료에 둔다.

- 계정 사용 가능 여부와 서비스별 적용 계약 확인.
- 운영 책임 주체·권리 요청 연락처 확정.
- 처리/보관 국가·처리 주체·목적·기간·필요 고지 확정.
- 관리자 복구·Vault·외부 백업과 탈퇴 파기/복원 절차 확정.
- 홈페이지 처리방침·동의 버전을 실제 조건에 맞춰 갱신.
- 운영진 권한·메일·실제 환경 시험을 별도로 마무리하고 사용자의 개통 지시를 받은 뒤 가입 스위치 검토.

문서 게시나 문의처 설정만으로 `PRIVACY_STORAGE_APPROVED`, 선수 가입·시즌·리그 메일을 열지 않는다.
