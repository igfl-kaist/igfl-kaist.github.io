## 디자인 방향

IGFL은 ISE & GSDS Futsal League의 약칭이다. 흰 배경, 읽기 쉬운 글자, 충분한 여백, 얇은 구분선을 사용한다. 연구실과 구성원들이 교류하는 리그의 분위기를 전달한다. 과도한 스포츠 효과나 순위 중심의 첫 화면을 피하고 소개 홈을 기본 진입점으로 둔다.

사용자는 흰 배경과 깔끔한 느낌, 기존 시안의 짙은 초록색 포인트와 전체 톤을 유지하기로 했다. 서체 크기, 카드 모서리와 문구는 같은 톤 안에서 다듬는다. 모집 상태에는 주황색을 사용한다. 시안의 모든 이름·팀·연구실·기록은 합성 예시이며 실제 가입·인증·저장·전송 기능은 없다.

전체 인계 기준은 [최종 구현 지침](IMPLEMENTATION_BRIEF.md)에 있다. 저장소에 보관한 [승인 시안 원본](design/igfl-approved-mockup.html)과 [사용 안내](design/README.md)를 함께 읽는다.

## 페이지와 이동

상단 공통 메뉴는 리그 소개, 랭킹보드, 팀, 선수로 구성한다. 현재 메뉴를 표시하고 모바일에서도 모든 메뉴를 사용할 수 있게 한다. 선수 등록과 로그인 버튼을 둔다. 로그인은 학교 이메일로 받은 6자리 코드를 입력하는 방식이며 5분 카운트다운·재발급·세션 유지와 로그아웃을 제공한다. 시안의 역할별 화면 둘러보기와 역할 선택기는 검토용이다. 실제 통신은 Apps Script 우선이며 CORS 검증에 따라 HTML Service 인증 화면을 대안으로 검토한다. 비밀번호 입력·복구는 제거한다.

OUR TEAM.’으로 한다. 팀 이미지 미등록 시 기존 글자 엠블럼 이미지를 기본값으로 사용한다. 주장·부주장은 팀 관리 → 팀 프로필에서 대표 이미지를 업로드할 수 있고 공개 팀 카드·상세에 반영한다. 시안은 JPG·PNG·WebP / 3MB 이하로 제안하고 선택 즉시 미리보기와 기본 이미지 복원을 제공한다. 실제 제한·크롭·업로드 저장 시점은 추후 확정한다. 시안의 파일 선택은 로컬 미리보기만 수행하고 이미지나 입력한 개인정보를 대화 상태에 저장하거나 서버로 전송하지 않는다. 공개 선수 디렉터리에는 이름·연구실·소속 팀·심판 가능 표시를 포함하고 학번·이메일·지도교수는 표시하지 않는다.

팀·선수 디렉터리는 방문할 때마다 무작위 순서로 노출한다. 필터 전환 중에는 같은 방문 순서를 유지해 카드가 계속 움직이지 않게 한다. 팀 원본 배열이나 순위 데이터를 섞지 않으며 랭킹보드는 Elo 순위를 유지한다. 팀 상세의 역할·구성원 관계와 무작위 노출 순서를 혼동하지 않는다.

## 기록 표시와 시안 가정

개인 득점은 현 시즌 선수별 최근 실제 출전 5경기의 정규시간 득점 상위 3위다. 선택기는 제거하고 최근 5경기로 고정한다. 5경기 미만은 실제 출전 수, 동률은 공동순위와 경계 동률 전원 표시, 0골은 빈 순위를 채우는 데 쓰지 않는다. [계산·집계 규칙](RATING_POLICY.md)을 따른다.

심판 공로는 현 시즌 공식 확정된 내부 심판 담당 경기 수 상위 3위다. 단순 배정·수락과 외부 심판은 기본 공로 보드에서 제외한다. 동률은 공동순위를 적용한다. 득점자와 별도 영역이며 개인 종합 점수는 만들지 않는다.

팀 Elo는 초기 1000·K32·척도400·최종 승패 1/0, 점수 차 제외다. 정확한 동률은 공동순위이고 정수로 표시한다. 순위표에 기준을 붙이며 기록이 없을 때 합성 기록으로 채우지 않는다. 화면의 동률 내 이름 순서를 대회 진출 우선권으로 쓰지 않는다.

## 상호작용과 검토 범위

시안에서는 상단 메뉴 이동, 팀 카드에서 상세 진입, 팀 가입 문의 작성·요청 대기 상태, 네 가지 선수 필터, 득점 집계 경기 수 변경을 직접 비교한다. 선수 등록, 주장·부주장 역할 전환, 팀 관리, 경기 일정·결과 입력과 확인 단계도 체험한다. 합성 데이터로만 동작하며 실제 인증·계정 생성·메일·메시지 전송·서버 저장·랭킹 갱신은 하지 않는다. 양 팀과 심판의 확인을 한 화면에서 전환하는 버튼은 디자인 검토용이며 실제 서비스의 권한 모델이 아니다.

## 모집 표시와 연락 흐름

주황색 모집 배지는 팀 이미지 위에서 눈에 띄되 팀명·주장·부주장을 가리지 않게 배치한다. 모집하지 않는 팀에는 배지를 표시하지 않는다. 팀 상세에는 모집 안내와 가입 문의 버튼을 둔다. 문의 영역에서 주장·부주장 이름을 확인하고 간단한 소개를 남겨 가입을 요청하는 안이다. 개인 이메일·전화번호 대신 홈페이지 내부 요청함을 사용하므로 기존 개인정보 공개 범위와 이메일 용도를 유지한다.

선수 필터는 ‘전체 · 팀 소속 · 무소속 · 심판’을 같은 모양의 버튼으로 한 줄에 둔다. 한 번에 하나를 선택하며 심판 버튼은 소속 유무와 무관하게 심판 가능한 등록 선수를 표시한다. 별도의 심판 체크박스와 소속 필터 조합은 최신 사용자 요청으로 대체되었다. 실제 배정 수락이나 해당 경기의 심판 중립성 검사는 선수 디렉터리의 단순 가능 표기와 별도다.

## 선수 등록과 팀 운영 화면

이메일 인증과 프로필 입력을 두 단계로 나눠 입력 부담을 줄인다. 교직원 선택 시 학번을 사번으로 바꾸고 지도교수를 ‘해당 없음’으로 비활성화한다. 다른 학과 대학원생은 실제 학과와 GSDS·ISE 소속 지도교수를 입력한다. 공개될 연구실과 비공개 정보의 범위를 입력 화면에 명시한다. 교직원이 연구실 대신 소속 부서를 공개 표기하는 것은 시안 제안이며 운영 정책은 추후 확인한다. 팀 선택은 선택 사항이고 기본값은 무소속이다. 선수 등록 자체는 즉시 완료하며 팀 선택으로 소속이 자동 확정된다고 표시하지 않는다.

이메일 단계는 ‘인증번호 받기 → 숫자 6자리 입력 → 인증하고 계속하기’다. 한 입력란에 숫자 키패드·붙여넣기·일회용 코드 자동완성 속성을 제공하고 05:00부터 남은 시간을 표시한다. 발급 후 5분 만료 시 새 번호를 요청하게 한다. 재발급하면 이전 번호는 무효이며 이메일을 바꾸면 재인증한다. 시안에서만 난수 체험 번호를 표시하고 실제 메일은 보내지 않는다. 인증·코드는 대화 상태에 저장하지 않는다. 시안의 오입력 제한 5회는 검토용 가정이며 실제 제한은 미정이다. 5분은 인증번호 유효시간으로 해석했다.

프로필 단계에는 경기당 심판 수당 20,000원과 팀별 10,000원 직접 지급을 표시한다. 짧은 ‘개인정보 수집 및 이용에 동의합니다 (필수)’ 체크박스와 수집 목적 안내를 두고 상세 안내를 접어서 제공한다. 기본 체크는 해제한다. 미동의 시 등록을 막는다. 보관 기간·탈퇴 후 처리 기준은 아직 미정이므로 상세 문구는 초안이며 실제 운영 전 완성해야 한다.

주장과 부주장은 ‘내 선수 활동 / 팀 관리 / 경기 일정 등록 / 경기 결과 등록’ 네 탭에서 같은 기능을 제공한다. 심판도 겸하면 심판 활동을 추가한다. 명단에는 이름·연구실·역할만 표시한다. 모집은 공개 카드에 반영하고 영입 동의는 팀에서 협의한 뒤 대표가 등록한다. 방출은 이름을 표시한 취소/방출하기 팝업을 거치며 취소 시 소속을 유지한다.

팀 관리에 새 주장·새 부주장 선택과 대표 교체 요청을 둔다. 요청 후 승인 대기를 표시하고 운영진 승인 전까지 기존 대표 권한을 유지한다. 운영진의 대표 교체 탭에서 승인·보완·이력을 관리하며 승인 시점에 새 권한을 적용한다.

6명 미만 팀은 참가 유예와 기한·현재 인원을 표시한다. 기간은 60일 기본안이며 정확한 일수는 운영 설정이다. 유예 중 공식 경기·현재 순위 참여는 보류하되 충원은 허용한다. 인원을 채우면 복귀하고 기한 만료 미충원은 리그 제외이며 과거 기록 삭제가 아니다.

경기 일정에는 본인 팀 소속 선수만 체크박스로 자동 표시한다. 상대 팀의 명단은 상대 팀 대표가 같은 경기에 연결해 등록한다. 내부 심판은 양 팀 외부의 심판 가능 선수를 체크박스 목록으로 제공해 여러 명에게 동시에 요청한다. 선택한 후보별로 요청 이메일 알림을 보내며 수락 자체는 홈페이지에서 한다. 요청 현황에는 수락 대기·거절·배정 확정·다른 심판 배정으로 요청 종료를 표시한다. 최초 유효 수락자 한 명만 확정하며 배정 전에는 ‘공식 등록 보류’다. 서버 확정 후 공식 등록 완료로 전환하고 뒤늦은 수락은 기존 배정을 바꾸지 않는다. 시안의 수락 순서 비교 버튼은 상황 체험용이다. 대진·일시·장소 변경 시 기존 요청을 종료하고 재요청하는 것은 시안의 보수적인 안이며 변경 정책은 추후 확정한다. 외부 심판은 이름과 수락 확인 체크박스를 제공하는 안이며 결과 최종 승인자는 운영진이다. 심판비는 안내만 표시하고 결제·정산 UI를 만들지 않는다.

결과는 전체 스코어를 받고 동점이면 승부차기를 펼친다. 자기 팀 출전·득점만 입력하고 합계를 검증한다. 양 팀 스코어를 대조해 불일치 시 확정을 막고 운영진에게 알린다. 미제출·불일치·이의 중 최종 승인 불가, 수정·재제출 후 양 팀 재확인을 유지한다. 비교 예시 버튼은 검토용이다. 공식 Elo 계산은 RATING_POLICY.md를 적용하고 자책골 등 예외는 확정된 세칙이 없을 때 검토 상태로 남긴다.

## 역할별 로그인 화면

일반 선수는 자기 프로필·기록·팀과 출전 예정 경기를 본다. 내 선수 활동의 팀 탈퇴는 팀명과 취소/탈퇴하기 팝업을 띄운다. 확인 시 대표 승인 없이 즉시 무소속이 되고 새 팀을 찾을 수 있다. 계정·지난 기록은 유지하며 대표가 직접 탈퇴해도 권한을 즉시 해제한다. 별도 이적 승인 기능은 없다. 무소속 화면은 모집 중인 팀 찾기와 가입 요청을 안내한다.

심판 겸 선수는 ‘내 선수 활동 / 심판 활동’을 모두 본다. 자기 선수 프로필은 실제 선택된 로그인 인물과 연결하고 선수로 출전하는 경기와 심판으로 배정되는 경기를 구분한다. 심판은 예정 경기 배정 요청의 일시·장소·양 팀·중립성·비용 안내를 확인하고 수락 또는 거절한다. 다른 후보가 먼저 수락했다면 요청 종료를 보여주고 수락 버튼을 제공하지 않는다. 완료 경기에서는 양 팀이 제출한 전체 스코어와 각 팀의 출전·득점을 읽기 전용으로 비교하고 최종 승인한다. 이견은 운영진 검토로 전달한다. 일반 선수의 비공개 개인정보나 상대 팀 기록 수정 기능은 노출하지 않는다.

운영진은 팀 등록 신청, 외부 심판 경기, 이의 제기·스코어 불일치 탭을 사용한다. 팀 신청은 인원·대표·구성원을 확인해 승인 또는 보완 요청한다. 외부 심판 경기는 양 팀 스코어 일치와 확인 완료 상태 및 외부 심판 확인을 거친 뒤 최종 승인한다. 분쟁·불일치는 원본 기록을 비교하고 메모를 남겨 양 팀에 수정·재제출을 요청하는 안이다. 보완·재제출 요청에는 사유가 필요하며 처리 이력을 남긴다. 시안의 운영 목록 일부는 각각 독립된 합성 예시이며 실제 메일이나 요청을 보내지 않는다.

모바일에서는 소개 영역과 기록 영역을 세로로 쌓고 팀·선수 카드 열 수를 줄인다. 긴 팀명·연구실명을 자르지 않고 줄바꿈한다. 순위표의 중요한 팀명·순위·Elo는 좁은 화면에서도 유지하고 부차적인 열을 줄인다. 필터 선택 상태와 결과 수를 함께 표시한다.
